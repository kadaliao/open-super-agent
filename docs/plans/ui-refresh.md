# 界面翻新：图标、底色、尺寸、反馈，再到 Bot 头部和页面头

2026-11-28 开始。起因：对照 [dsh-bots](https://github.com/kadaliao/dsh-bots) 看自己的界面，觉得不够现代。
问题不在功能，在四个视觉习惯，再加几处结构：

1. 最显眼的位置用文字符号当图标（`◆ ▤ ⊞ ⚙ ★ ⚠ ✓ ✕ ＋ ↑ 🎙 ☰ ›`），粗细大小各不相同，和已有的线条图标混在一排。
2. 卡片、数据块、输入框、看板列几乎都是“灰底 + 边框”，叠在偏灰的背景上，整页一片中灰，没有重点。
3. 尺寸大而圆，档位太多：字号 20 多种（12 / 12.5 / 13 / 13.5 / 14 各用了几十次），圆角 6–26px 混用。
4. 交互反馈少：115KB 样式里 15 处过渡、3 处键盘焦点样式，没有照顾“减少动态效果”。
5. 结构：Bot 的头部只有一条细栏，八项功能挤在右栏的八个文字标签里；侧栏看不出 Bot 正在干什么；
   看板、观测这些页只有一个标题，没有一句说明和汇总。

不做的：不换几何头像；不加品牌色（继续黑白灰，颜色只来自头像和状态）；你自己的消息气泡不改成实心黑；
不照搬 dsh-bots 的双层侧栏和“谁派给谁”的消息行（那是功能，不是翻新）。

## 一、设计规范（所有分工都按这个来）

变量都定义在 `web/src/styles.css` 最上面的 `:root`（夜间）和 `:root[data-theme="light"]`（明亮）。
**已有的变量名不改**（`--bg --bg2 --bg3 --line --fg --fg2 --fg3 --acc --acc-fg --warn --bad --good --link --r --side --panel`），
只调数值、加新变量。下面的数值是起点，做的时候看着截图微调，但档位数量不能变多。

### 底色和层次

| 变量 | 用在哪 | 明亮 | 夜间 |
|---|---|---|---|
| `--bg` | 内容区的底（对话、看板、观测、设置右侧、弹窗） | `#ffffff` | `#111113` |
| `--bg2` | 侧栏；一层浅灰（看板的列、分段开关的槽、引用块） | `#f7f7f5` | `#18181b` |
| `--bg3` | 悬停、选中、行内代码、你的消息气泡 | `#efefec` | `#222226` |
| `--card`（新） | 卡片的底 | `#ffffff` | `#18181b` |
| `--line` | 细线：卡片边、分隔线 | `#e8e8e5` | `#2a2a2f` |
| `--line2`（新） | 稍重的线：输入框、按钮的边，卡片悬停时的边 | `#d9d9d5` | `#3a3a40` |
| `--hover`（新） | 透明底上的悬停 | `color-mix(in srgb, var(--fg) 6%, transparent)` | 同左 |
| `--ring`（新） | 输入框聚焦时外面那圈 | `color-mix(in srgb, var(--fg) 10%, transparent)` | `… 16% …` |
| `--good-bg --warn-bg --bad-bg --info-bg`（新） | 状态标签的淡色底 | 对应颜色 12% 混透明 | 对应颜色 16% |

规则：

- **卡片 = `--card` 底 + 1px `--line`**，不再用 `--bg2` 当卡片底。能点的卡片悬停时边变 `--line2`、加 `--shadow-sm`。
- **灰底只留给**：侧栏、悬停和选中、看板的列（列自己不要边框）、分段开关的槽、行内代码和小标签、你的消息气泡、引用和次要说明块。
  同一处不要既灰底又描边再套一层灰。
- **输入框**（`input / textarea / select`）：`--bg` 底（夜间用 `--bg2`）、1px `--line2`；聚焦时边变 `--fg2`，外面一圈 3px `--ring`。
  对话的输入框（`.composer`）同理，圆角 `--r-xl`。
- **状态标签**统一成一种：`.tag`（高 20px、圆角 `--r-sm`、字号 `--fs-2`、可带一个 6px 圆点），
  `.tag.good / .warn / .bad / .info` = 文字用状态色、底用对应的 `--*-bg`；不带状态的是 `--bg3` 底 `--fg2` 字。
  数字角标（`.badge`）还是实心的，不变。
- 夜间里卡片靠 `--card` 比 `--bg` 亮一点来分层，线只是辅助。

### 字号（8 档，不再有半像素）

| 变量 | 桌面 | 窄屏（≤760px） | 用在哪 |
|---|---|---|---|
| `--fs-1` | 11px | 11px | 角标、极小的标注 |
| `--fs-2` | 12px | 12px | 时间、说明、标签 |
| `--fs-3` | 13px | 14px | 次要文字：预览、表格、小按钮、按钮 |
| `--fs-4` | 14px | 15px | 界面主文字：导航、输入框、卡片标题 |
| `--fs-5` | 15px | 16px | 阅读的正文：对话、文档 |
| `--fs-6` | 17px | 17px | 小节标题、Bot 名字 |
| `--fs-7` | 20px | 20px | 页面标题、数据块的大数字 |
| `--fs-8` | 24px | 24px | 欢迎页、引导页的大字 |

旧值怎么归：10–11 → `--fs-1`；11.5–12.5 → `--fs-2`（次要文字里偏重要的可以进 `--fs-3`）；13、13.5 → `--fs-3`（13.5 里当主文字用的进 `--fs-4`）；
14、14.5 → `--fs-4`；15、15.5 → `--fs-5`；16–19 → `--fs-6`；20–22 → `--fs-7`；24–28 → `--fs-8`。
归并后父子两层撞成同一档时，用颜色（`--fg2 / --fg3`）或字重区分，不要再造一档。`em` 写的相对字号（Markdown 标题、行内代码）不动。
根字号（`:root` 的 `font-size`）改成 `var(--fs-5)`。

### 圆角（5 档）

| 变量 | 值 | 用在哪 | 旧值 |
|---|---|---|---|
| `--r-xs` | 4px | 行内代码、最小的标签 | ≤5 |
| `--r-sm` | 6px | 标签、小按钮、菜单项 | 6、7 |
| `--r-md` | 8px | 按钮、输入框、列表行、导航项 | 8、9、10 |
| `--r-lg` | 12px | 卡片、菜单、浮层 | 11、12、14 |
| `--r-xl` | 16px | 弹窗、对话输入框、消息气泡 | 16、18、20（气泡）、26 |
| `--r-full` | 999px | 筛选用的胶囊、圆点 | 胶囊上的 20 |

`--r` 留着，等于 `--r-lg`。圆形（头像、圆按钮、开关的滑块）还是 `50%`。气泡的尖角用 `--r-xs`。

### 控件高度

`--h-sm: 26px`、`--h-md: 32px`、`--h-lg: 36px`。`.btn` 固定 `--h-md` 高、左右 12px、字号 `--fs-3`、字重 500、圆角 `--r-md`；
`.btn.small` 用 `--h-sm`、圆角 `--r-sm`（不再是胶囊）；单行输入框和 `select` 用 `--h-md`。
触屏（`@media (pointer: coarse)`）上 `--h-sm: 32px; --h-md: 40px; --h-lg: 44px`，手指点得中。

### 阴影和动效

- `--shadow-sm: 0 1px 2px rgba(0,0,0,.05)`（卡片悬停）、`--shadow-md: 0 6px 20px rgba(0,0,0,.10)`（菜单、浮层）、
  `--shadow-lg: 0 20px 56px rgba(0,0,0,.18)`（弹窗）；夜间各自加重到 `.3 / .45 / .6`。
- `--t-fast: .12s`、`--t-med: .18s`、`--ease: cubic-bezier(.2, .8, .2, 1)`。
- 能点的东西（按钮、行、卡片、标签、输入框）的底色、边、文字色、阴影都过渡 `--t-fast`。
- 键盘焦点：`:focus-visible` 统一 `outline: 2px solid var(--link); outline-offset: 1px`（输入框用上面的聚焦样式，不叠 outline）。
- 出现：弹窗淡入加从 0.98 放大到 1（`--t-med`），菜单和浮层淡入加 4px 位移，右栏和页面切换淡入。**消息本身不加入场动画**（重渲染会反复触发）。
- `@media (prefers-reduced-motion: reduce)`：位移、缩放、循环动画（头像晃动、眨眼、脉冲）都停，只留很短的淡入。

### 图标

全部用 `web/src/icons.tsx` 的 `<Icon name size />`（Lucide，24 格、线宽 2、圆头）。缺的从 Lucide 取同名路径加进去。
尺寸三档：14（标签、行内）、16（导航、按钮）、18（头部的图标按钮）。界面里不再出现当图标用的文字符号和 emoji。

## 三、各块的验收

**base**
- `:root` 里有上面全部变量，两套主题都有；`styles.css` 等文件里不再有写死的半像素字号，圆角和字号基本都走变量（确实特殊的写死值留注释说明）。
- 观测页、应用市场、设置、看板、任务卡片、记忆列表：卡片是白底细线，不再灰底描边；输入框是白底、聚焦有一圈。
- 所有能点的东西有悬停过渡，Tab 键走一遍看得见焦点；系统开了“减少动态效果”时没有位移和循环动画。
- 手机宽度下字号、点击区域不比现在小。`index.html`、`theme.ts` 里的主题色跟着新的 `--bg` 改，夜间启动不闪白。

**icons**
- 在 `web/src` 里搜这些符号，当图标用的一个不剩：`◆ ▤ ⊞ ⚙ ★ ⚠ ✓ ✕ ＋ ↑ 🎙 ■ ☰ › 💬`（写在说明文字、Markdown 内容里的不算）。
- 侧栏的 logo 用一个 SVG（照 `web/public/favicon.png` 的形状画，或者保留菱形但用 SVG 画），加载页同理。
- 图标和文字对齐（垂直居中、间距一致），明暗两套都跟着文字色。

**bot**
- 对话头部两行：头像（36px）、名字（`--fs-6`）、主 Bot / 群聊人数的标签；第二行是状态（空闲 / 正在做什么，带圆点）和一句职责。
  右边的操作都是图标按钮（新话题带字），“详情”换成“侧边面板”的图标。窄屏上收成一行，不挤掉名字。
- 右栏的八个标签改成带下划线的一排，放得下（默认宽度加到 380px），放不下时能横着滑、边上渐隐；英文也要放得下。
- 侧栏：导航项 34px 高、图标 16px；对话项在 Bot 忙的时候第二行显示“正在做：……”，等你处理时用警示色的图标和字，头像角上有状态点；
  空闲时照旧显示最后一条消息。不要每秒重画整个侧栏。

**pages**
- 一个共用的 `PageHead`：标题、一句说明、右边放操作；看板、观测、应用、资料库都用它。
- 看板：标题下一行汇总（这一周多少需求、完成几个、进行中几个、等你几个）；时间筛选从下拉框改成一排胶囊；
  列是一层浅灰、不描边，卡片白底细线、悬停有反馈；空的列有一句话。
- 观测：数据块白底细线，数字用 `--fs-7`；表格行高和对齐统一。应用市场和资料库的卡片、标签跟规范走。

**cards**
- 任务卡片、确认卡片、提问卡片、“说不准”卡片：白底细线，状态用 `.tag`，等你处理的用 `--warn-bg` 底而不是一圈橙线加橙字。
- 系统行（“✓ 已允许……”）用图标加字；任务面板里的步骤列表行高一致、状态用图标和 `.tag`。
- 输入框上下的提示、附件条、语音状态跟规范走。
