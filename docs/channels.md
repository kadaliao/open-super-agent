# 聊天软件（Telegram、飞书、钉钉、企业微信、Discord）

在 Telegram、飞书、钉钉、企业微信或 Discord 里直接和 Bot 说话，不用开网页。手机上的推送也就交给了聊天软件，比 PWA 推送可靠。

在网页的 **设置 → 聊天软件** 里添加。收消息走长轮询（Telegram）和长连接（其余几家），**服务器不需要公网地址**，本机跑也能用。

## 怎么用

- 每个连接是聊天软件里的一个机器人账号，绑定这边的一个对话：某个 Bot 的私聊，或者一个群聊。
  在聊天软件里说的话和网页上是**同一个对话**，两边都能看到记录；网页上会标“来自 Telegram”“来自钉钉”这样的来源。
- 想和几个 Bot 分别聊，就给每个 Bot 建一个机器人账号。绑定群聊时，每条回复前面带着 Bot 的名字。
- 发到聊天软件的：Bot 的回复、任务结果（定时任务的结果也会）、任务取消、群聊里的交接。Bot 在想的时候 Telegram 和 Discord 显示“正在输入”，飞书在你那条消息上加一个“敲键盘”表情。
  不发的：你在网页上说的话、流式输出和任务的中间过程。
- 需要你确认的操作变成**带按钮的卡片**（允许一次 / 拒绝 / 总是允许）。Bot 请你帮忙（登录、验证码）时，卡片上有“处理完了”“处理不了”，
  接手电脑要去网页上操作，卡片里有链接。不管在哪边处理的，卡片都会更新成结果（钉钉改不了发出去的消息，另发一条结果）。
  - 回复 **“允许 #12”“拒绝 #12”“总是允许 #12”“处理完了 #12”** 等于点按钮（`#` 可以不写，编号在卡片上）。钉钉的确认就是这样做的：
    卡片上的“按钮”是链接，点一下替你发出这句话。
  - 也可以直接回复“同意”“不行”，Bot 会照办。
- 命令：`/new` 开始新话题，`/stop` 停下这个对话里正在做的任务，`/help` 看说明。`/技能名` 和网页上一样。
- 发文件或图片：存到电脑的 `/data/workspace/uploads`，消息里带上路径，Bot 可以接着处理（和网页上传附件一样，电脑没开时会先开机）。
- 语音消息：钉钉和企业微信会把语音转成文字发过来，直接能用；Telegram、飞书、Discord 暂不支持，可以用输入法的语音转文字。
- 只支持私聊。把机器人拉进聊天软件的群里不会有反应。

**网页地址**：设置 → 聊天软件 最下面。消息里的页面链接（`/library/pages/3`）和“去网页接手”按钮会补上这个地址。
第一次添加连接时自动填成你当时打开网页用的地址；手机上要能打开，最好是 https（Telegram 的链接按钮只接受 https）。

## Telegram

1. 在 Telegram 里打开 [@BotFather](https://t.me/BotFather)，发送 `/newbot`，按提示起名字和用户名。
2. 把它回复里的 token（像 `123456789:AAH…`）贴到 设置 → 聊天软件 → Telegram，选好和谁对话，点连接。
3. 页面上出现 6 位配对码和“在 Telegram 里打开”按钮。点按钮会打开你的机器人并自动带上配对码，按“开始”就配好了；也可以直接把配对码发给它。

服务器在国内的话连不上 Telegram，要给 open-super-agent 设置代理环境变量（httpx 会自动使用）：

```bash
HTTPS_PROXY=http://127.0.0.1:7890 uv run uvicorn osa.server:app --port 8765
```

**同一个 token 只能一处在用。** 两台服务器（比如本机和公网服务器）连同一个机器人会互相顶掉，状态显示“这个机器人在别处也在收消息”。
给每处各建一个机器人，或者停用其中一处的连接。

## 飞书

用企业自建应用，需要你在飞书企业里有创建应用的权限。

1. 打开 [飞书开发者后台](https://open.feishu.cn/app)，**创建企业自建应用**，在“添加应用能力”里添加**机器人**。
2. **权限管理** 里开通（搜索权限名）：

   | 权限 | 用途 |
   |---|---|
   | 读取用户发给机器人的单聊消息（`im:message.p2p_msg:readonly`） | 收你的消息 |
   | 以应用的身份发消息（`im:message:send_as_bot`） | 回复、发卡片、更新卡片 |
   | 获取与上传图片或文件资源（`im:resource`） | 收你发的图片和文件 |
   | 发送、删除消息表情回复（`im:message.reactions:write_only`） | 可选：显示“正在输入” |

3. 把“凭证与基础信息”里的 **App ID** 和 **App Secret** 填到 设置 → 聊天软件 → 飞书，点连接。用海外版 Lark 的选“Lark”。
4. 连上之后回到开发者后台的 **事件与回调**：
   - 事件配置：订阅方式选**使用长连接接收事件**，添加事件“接收消息”（`im.message.receive_v1`）。
   - 回调配置：订阅方式也选长连接，添加回调“卡片回传交互”（`card.action.trigger`）。确认卡片上的按钮靠它。

   飞书要求保存长连接设置时，应用已经连着，所以要先做第 3 步。
5. **版本管理与发布** 里创建一个版本并发布（要企业管理员审核，你自己是管理员的话直接通过）。
6. 页面上点“在飞书里打开机器人”，把配对码发给它。

同一个应用连了多处时，飞书只把消息随机推给其中一处，所以一个应用只在一个地方连。

## 钉钉

用企业内部应用的机器人，需要你在钉钉组织里有创建应用的权限（管理员或被授权的开发者）。

1. 打开 [钉钉开发者后台](https://open-dev.dingtalk.com)，在“应用开发”里创建一个**企业内部应用**。
2. “添加应用能力”里添加**机器人**，在机器人配置里把**消息接收模式**选成 **Stream 模式**，填好名字后发布机器人。
3. **权限管理** 里搜索“机器人”，开通**企业内机器人发送消息权限**。

   你刚发完消息时，回复走消息自带的回复地址，不需要这个权限；隔久了才发的（任务结果、定时任务）要用它。
   没开通时连接会显示“发不出消息”。收图片和文件提示没有权限时，按提示开通对应的权限。
4. 把“凭证与基础信息”里的 **Client ID**（原来叫 AppKey）和 **Client Secret**（AppSecret）填到 设置 → 聊天软件 → 钉钉，点连接。
   名字可以不填，只在网页上显示。
5. **版本管理与发布** 里发布应用。然后在钉钉里搜索机器人的名字，打开和它的单聊，把配对码发给它。

确认请求是一条消息，下面是“允许一次 ｜ 拒绝 ｜ 总是允许”三个链接，点一下替你发出“允许一次 #12”。英文界面下链接和发出的文字是英文（“Allow once #12”），自己打字回复时中英文都认。
钉钉的互动卡片按钮要先在卡片平台建模板，为了少一步配置，这里没有用卡片。

同一个应用连了多处时，钉钉只把消息推给其中一处，所以一个应用只在一个地方连。

## 企业微信

用企业微信的**智能机器人**。

1. 在企业微信里创建一个智能机器人（管理后台或工作台里的“智能机器人”），也可以用已有的。
2. 打开机器人的配置页面，开启 **API 模式**，连接方式选**长连接**，拿到 **Bot ID** 和 **Secret**。
3. 填到 设置 → 聊天软件 → 企业微信，点连接。名字可以不填，只在网页上显示。
4. 在企业微信里找到这个机器人，打开单聊，把配对码发给它（第一次打开单聊时它会提示你发配对码）。

- 确认请求是按钮卡片；在卡片上点的，卡片会改成结果。在网页上处理的，企业微信不让事后改卡片，会另发一条结果。
  卡片上放不下的长内容（比如要发的邮件正文）会先单独发一条。
- 企业微信规定机器人只能给发过消息的人主动发，每个对话每分钟最多 30 条。配对时你已经发过了，平时不用管。
- **同一个机器人只能有一处连着**，别处连上后这边会被顶掉，状态显示“这个机器人在别处也连上了”。把机器人改成回调模式（填 URL 的那种）后这里也会断开。

## Discord

1. 打开 [Discord Developer Portal](https://discord.com/developers/applications)，点 **New Application** 建一个应用。
2. 左边的 **Bot** 页面点 **Reset Token**，复制 token，贴到 设置 → 聊天软件 → Discord，点连接。
   不用打开任何 Privileged Gateway Intents：机器人只收私信，私信的内容不需要特权。
3. 连上后页面上有两个按钮：
   - **① 把机器人加到你的服务器**：Discord 只让和机器人在同一个服务器里的人私信它，选一个你自己的服务器（没有就先建一个）。机器人不需要任何权限，也不会在服务器的频道里说话。
   - **② 打开机器人，发私信**：在机器人的主页上发消息，把配对码发给它。

服务器在国内的话连不上 Discord，和 Telegram 一样要设置 `HTTPS_PROXY`。

**同一个 token 可以多处连**，但每一处都会收到消息、各回一遍，所以也只在一个地方连。

## 安全

- **只有配对的人能用。** 配对码 6 位，30 分钟内有效，输错 10 次作废；配对之后，别人发给机器人的消息一律不理，也点不了卡片上的按钮。
- 换手机号、换账号时，在连接上点“重新配对”，原来的私聊就失效了。
- token、App Secret、Client Secret 加密存在保险库（名字是 `channel_<编号>`），不会出现在聊天记录和接口里；删除连接时一起删掉。
- 消息内容会经过聊天软件自己的服务器。不想让聊天内容离开自己机器的，别用这个功能。

## 常见问题

| 现象 | 原因和处理 |
|---|---|
| Telegram 一直“出错了：连不上 Telegram” | 服务器访问不了 api.telegram.org，设置 `HTTPS_PROXY` 后重启 |
| Discord 一直“连不上 Discord” | 同上，服务器访问不了 discord.com，设置 `HTTPS_PROXY` 后重启 |
| “这个机器人在别处也在收消息” | 同一个 token 有两处在用，见上面 |
| “token 失效了” | 在 @BotFather 里删了机器人或重置了 token，删掉连接重新添加 |
| 飞书添加时报“应用还没开启机器人能力” | 第 1 步没加机器人能力，或者加了还没发布版本 |
| 飞书能连上，但发消息没反应 | 事件订阅不是长连接、没加“接收消息”事件、没开通单聊消息权限，或者改完没有发布新版本 |
| 飞书卡片按钮点了提示出错 | 没配置“卡片回传交互”回调（订阅方式也要选长连接） |
| 图片和文件存不上 | 飞书：没开通“获取与上传图片或文件资源”；Telegram：机器人只能收 20 MB 以内的文件 |
| 钉钉连上了，发消息没反应 | 机器人的消息接收模式不是 Stream 模式，或者改完没有发布；在群里 @ 机器人不算，要单聊 |
| 钉钉“发不出消息：应用还没开通企业内机器人发送消息权限” | 权限管理里开通后重新发布应用 |
| 钉钉添加时报“Client ID 或 Client Secret 不对” | 填的是“凭证与基础信息”里的 Client ID 和 Client Secret，不是 AgentId 或 corpId |
| 企业微信添加时报“Bot ID 或 Secret 不对” | 机器人的 API 模式没选长连接，或者 Secret 重新生成过 |
| 企业微信“这个机器人在别处也连上了” | 另一处（另一台服务器、别的程序）用同一个机器人连着，停掉那边，在这边点停用再启用 |
| Discord 私信不了机器人 | 还没把机器人加到你所在的服务器，先点“把机器人加到你的服务器” |
| Discord “token 失效了” | 在 Developer Portal 里重置过 token，删掉连接重新添加 |
| 卡片里没有“去网页接手”按钮 | 设置 → 聊天软件 里的网页地址没填，或者不是 https |
