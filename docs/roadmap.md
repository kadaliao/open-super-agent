接下来不再按编号阶段推进，改为按下面几个方向持续做。哪些已经做好，看 [更新日志](../CHANGELOG.md)。

先做哪个主要看大家的反馈。想要的功能欢迎 [提 issue](https://github.com/kadaliao/open-super-agent/issues/new/choose)，注明属于哪个方向。

## 方向

### 应用生态

Bot 能干多少活，取决于它能连多少应用。现在收录了 40 个，每个应用一份清单文件（`osa/catalog/apps/`），
提个 PR 就能上架，不用懂项目代码，见 [给应用市场加一个应用](apps.md)。

- **应用交给社区收录**：项目这边不再一个个补应用，只补清单格式和连接方式上缺的能力，让更多应用能写成一份清单：
  - 代为登录再把令牌交给应用：Google 云端硬盘、日历要靠它（Google 官方的 MCP 还只对开发者预览开放，社区的 workspace-mcp 要我们先登录）
  - “把跳转后的地址粘贴回来”：飞书的一键登录只接受 localhost 回调，飞书的个人链接 7 天过期、以后会下线
- **Bot 模板交给社区**：内置了 4 个（资讯助手、邮件管家、项目观察员、出行助手），新的模板写一个 YAML 提 PR，见 [写一个 Bot 模板](templates.md)。

### 更多客户端

现在只有网页和 PWA。PWA 在 iPhone 上推送、后台运行、系统分享菜单都受限制；很多人也更习惯在已有的聊天软件里说话。

- **聊天软件接入**：Telegram、飞书、钉钉、企业微信、Discord 已经做好（确认卡片变成消息里的按钮，效果类似 Grok Bot 在 X 上 @bot；
  钉钉、企业微信的语音消息直接转成文字）。接下来：把机器人拉进聊天软件的群里使用；Telegram、飞书、Discord 的语音消息转文字。
- **macOS / Windows 桌面端**：菜单栏、全局快捷键、系统通知、把文件拖给 Bot。
  最有价值的是**用本机当 Bot 的电脑**：作为第三种电脑后端（和 Instabox、本地 Docker 并列），Bot 能用你已经登录的浏览器和本机文件。
  这台电脑上有你的真实数据，确认规则要比云端电脑更严。
- **iOS / Android 原生 App**：可靠的推送、在系统分享菜单里“发给 Bot”、原生语音输入。

### 电脑

- **多台电脑**：现在所有 Bot 共用一台电脑，任务排队独占，后台任务一多就要等。改成按 Bot 或按任务分配电脑，任务可以并行。
- **演示一遍扩展到整个桌面**：现在只录浏览器里的操作，终端和桌面应用里的操作录不到。
- **快照与回滚**：任务开始前存一个快照，做坏了一键回到之前的状态（Instabox 的快照不收费）。

### Bot 能力

- **记忆和资料库按语义检索**：现在只把最近更新的 80 条记忆放进提示词，更早的就用不上了；资料库只能浏览。条目多了以后要能按意思找。
- **语音对话**：现在只有语音输入（浏览器自带的识别），之后加上语音回复和实时语音对话。

### 好部署、好上手

- **界面英文版**：README 有英文版，界面还只有中文。

## 还在考虑

- **多人与团队**：多个账号、共享 Bot、按人分权限。第一阶段把它放在“暂不做”里，有需求再做。
- **开放 API**：让脚本和别的程序给 Bot 发消息、派任务、取结果。
- **浏览器插件**：把正在看的网页发给 Bot，或者让 Bot 借用你自己的浏览器。

## 不做

- 绕过验证码或人机校验。遇到这类步骤，Bot 一律请人接手（见 [CONTRIBUTING.md](../CONTRIBUTING.md)）。

## 已完成：对齐 Grok Bot

| 阶段 | 内容 |
|---|---|
| P1 Bot 与对话 | 多 Bot、流式输出、任务卡片、设置、费用统计 |
| P2 电脑 | Instabox 和本地 Docker 两个后端、实时画面、接手 / 交还、任务排队 |
| P3 确认与应用 | “总是允许”规则、在界面里管理应用、保险库、`@应用`；网页操作改用 CDP |
| P4 技能与定时任务 | `/技能`、每个 Bot 的定时任务和运行记录 |
| P5 记忆与资料库 | 长期记忆、“记住这个”、新话题、页面与分享链接、文件与附件 |
| P6 群聊 | 2–6 个 Bot、`@` 和 `@所有人`、协调者分派、Bot 之间交接、确认卡片回到私聊 |
| P7 演示一遍和移动端 | 录一遍操作生成技能、语音输入、PWA 与推送通知、手机布局 |

当时的功能对照、架构设计和每个阶段的验收标准见 [对齐 Grok Bot](grok-bot-parity.md)。
