# 路线图

和 Grok Bot 对齐的功能已经全部做完（P1–P7，v0.3.0），之后又加了登录、应用市场、五个聊天软件、Docker Compose 部署、macOS 桌面 App、iPhone App和多媒体消息。
接下来不再按编号阶段推进，改为按下面几个方向持续做。哪些已经做好，看 [更新日志](../CHANGELOG.md)。

先做哪个主要看大家的反馈。想要的功能欢迎 [提 issue](https://github.com/kadaliao/open-super-agent/issues/new/choose)，注明属于哪个方向。

## 近期先做

- **iPhone App 公开**：0.23.0 在 TestFlight 上内部测试，真实推送在锁屏上能解开、点通知能打开对应的对话。接下来在真机上把相机扫码、
  本地网络权限、正式环境的推送测一遍，然后开公开测试，再提交 App Store。见 [iPhone App](mobile.md)。
- **Windows 桌面 App**：macOS 版已经发到 0.23.0，接着做 Windows 版。
- **团队**：一键雇用一支团队（一人公司、研发小队、内容工作室、研究台这类模板，一次建好几个 Bot、各自的技能和定时任务），每个团队有负责人；
  有了团队以后主 Bot 只调度，活交给负责人，由负责人拆给队友、汇总后回你。这会改变现在“谁做完谁的结果直接出现在对话里”的样子，动手前先定下来，
  见 [计划 → 第三波](plans/tasks-board.md#第三波团队动手前要定)。

## 方向

### 应用生态

Bot 能干多少活，取决于它能连多少应用。现在收录了 40 个，每个应用一份清单文件（`osa/catalog/apps/`），
提个 PR 就能上架，不用懂项目代码，见 [给应用市场加一个应用](apps.md)。

- **应用交给社区收录**：项目这边不再一个个补应用，只补清单格式和连接方式上缺的能力，让更多应用能写成一份清单：
  - 代为登录再把令牌交给应用：Google 云端硬盘、日历要靠它（Google 官方的 MCP 还只对开发者预览开放，社区的 workspace-mcp 要我们先登录）
  - “把跳转后的地址粘贴回来”：飞书的一键登录只接受 localhost 回调，飞书的个人链接 7 天过期、以后会下线
- **Bot 模板交给社区**：内置了 4 个（资讯助手、邮件管家、项目观察员、出行助手），新的模板写一个 YAML 提 PR，见 [写一个 Bot 模板](templates.md)。

### 更多客户端

网页在手机上也能用，但推送、后台运行、系统分享菜单都受限制；很多人也更习惯在已有的聊天软件里说话。

- **聊天软件接入**：Telegram、飞书、钉钉、企业微信、Discord 已经做好（确认卡片变成消息里的按钮，效果类似 Grok Bot 在 X 上 @bot；
  钉钉、企业微信的语音消息直接转成文字）。接下来：把机器人拉进聊天软件的群里使用；Telegram、飞书、Discord 的语音消息转文字。
- **macOS / Windows 桌面端**：macOS 版已经发到 0.23.0（见 [桌面 App](desktop.md)）：自带运行环境，也能连接服务器；系统通知、菜单栏、全局快捷键、把文件拖给 Bot、自动更新（装好后界面顶上提示“重启更新”）。
  **用本机当 Bot 的电脑**（已完成，电脑类型 `host`）：Bot 用你电脑上装的 Chrome（单独的配置目录），文件只在工作文件夹里，
  终端默认关；上传文件、写文件、提交这类操作默认先问。接下来做 Windows 版。
- **iPhone App**（TestFlight 内测，见 [iPhone App](mobile.md)）：和桌面 App 一样用 Tauri 2，界面就是服务器的网页。
  已经做好：扫码连接和登录；推送经推送中转送到手机，内容端到端加密，App 关着也能收到；下载后弹分享面板；图标上的待确认数。
  接下来：公开测试，然后上架（先上中国大陆以外的地区，中国区要先办 APP 备案）；系统分享菜单里“发给 Bot”；锁屏上直接批准或拒绝；原生语音输入。
- **Android App**：国内没有谷歌推送，要接各家手机厂商的推送，等 iPhone App 稳定后再做。

### 电脑

- **几个任务同时用电脑**（已完成）：原来所有任务排队独占一台电脑，后台任务一多就要等。没有做成“多台电脑”，
  而是同一台电脑里每个任务一个浏览器窗口：登录状态和文件照样共用，Instabox 免费版（只能有一台机器）和内存小的服务器也能用。
  任务的截图、点击、输入都只作用在自己的窗口里，同时做也互不干扰；同时用的任务数在设置里调。
- **真正的多台电脑**：一台电脑的内存、CPU 不够用时再考虑，比如本地 Docker 起几个容器、共用一个工作目录。
- **控制整个桌面**：macOS 上已经能用（本机给了权限就行，见 [配置](configuration.md#电脑)）。还没做的：Windows；多个显示器；
  按界面元素的列表操作（现在是看截图点坐标，不能看图的模型用不了）；“演示一遍”跟着扩展到桌面应用。
- **服务器上的 Bot 把任务派到你的电脑**：macOS 上已经能用，可以同时连好几台 Mac（在 Mac 的 App 里允许，见 [桌面 App](desktop.md)）。还没做的：Windows；定时任务指定在哪台 Mac 上做。
- **快照与回滚**：任务开始前存一个快照，做坏了一键回到之前的状态（Instabox 的快照不收费）。

### Bot 能力

- **任务能对话、能接着做**（已完成，计划见 [把事交出去、看得见做到哪](plans/tasks-board.md)）：给正在做的任务补一句、任务停下来问你、做完回一句接着做、重试；
  服务重启后接着做，临时出错自己重试；重启、卡住、停下时正在执行的写操作不重做，先查再问你。见 [功能一览](features.md#bot-和对话)。
- **需求看板和项目**（已完成，同一份计划）：每件事一张卡，列由背后的任务决定；项目带编号、简介、目录和项目记忆；对话里派的任务自动归卡。见 [功能一览 → 需求看板](features.md#需求看板)。
- **记忆会自己整理**（已完成，同一份计划）：截止日、置顶、每天夜里合并精简、每日摘要，能撤销。
- **Bot 之间私信**（已完成）：不用拉群，Bot 也能私信另一个 Bot 请它帮忙，回信自动回到原来的对话（对齐 Grok Bot 的“Bot 给 Bot 发消息交接工作”）。
- **语音对话**：现在只有语音输入（浏览器自带的识别），之后加上语音回复和实时语音对话。
- **多媒体消息**（已完成，计划见 [多媒体消息、对话里画图、链接卡片](plans/multimedia.md)）：对话里显示图片和文件、Bot 直接看你发的图；
  Bot 在对话里画图（画之前先确认）；YouTube、B 站、X 和普通网页的链接显示成卡片或播放器。
  后来又加了照着图片画、生成视频，各家接口写成配置里的配方（见 [配置](configuration.md#画图和生成视频的配方)）。
- **搜索网页、读网页能换服务**（已完成）：设置里选用哪几家、排先后，出错换下一家；`search_posts` 搜 X、Reddit、小红书上的帖子（见 [配置](configuration.md#搜索和读网页)）。
- **资料库变成大家一起写的文档**（进行中，拆成独立项目 [Open Agent Docs](https://github.com/kadaliao/open-agent-docs)，做好了再接回来）：
  0.23.0、0.24.0 里做过一版（按段编辑、块编辑器、评论叫醒 Bot、版本历史、数据库、外部 Agent 经 MCP 读写、从 Notion 导入，见 [计划](plans/docs.md)、[v2 计划](plans/docs-v2.md)），
  0.25.0 起先撤回：资料库回到 Markdown 页面，Bot 之间交接工作照旧借 Notion。

### 好部署、好上手

- **设置改版，模型在界面里配**（已完成）：
  - 设置页改成左侧导航、按类分组（模型与费用、电脑、安全、连接、自动化、数据），选了就保存。
  - 模型服务在界面里添加：选一个服务商（DeepSeek、OpenAI、OpenRouter、硅基流动、阿里云百炼、智谱、Kimi、Ollama，
    或者任何兼容 OpenAI 的地址），填 API Key，点“测试连接”确认能用，并拉出它的模型列表。密钥存进保险库，不用再改 `config.yaml` 和环境变量；
    原来写在 `config.yaml` 里的照样能用。
  - 对话、后台任务、汇总、整理各自从模型列表里选（可以搜索，也可以直接填名字），点一下就能测试，顺便测出能不能看图。
    按意思检索用的 embedding 模型也在这里选。
  - 单价自动获取：每天从 models.dev 更新，选模型时就能看到价格和能不能看图，费用统计也按它算。
  - 对话或后台任务的模型没法用时，对话页提示去设置里配，不用先读文档。
- **第一次打开时的引导**（已完成）：接上模型服务并选一个模型 → 给 Bot 起名字或从模板装一个 → 连一个常用应用，每步都能跳过；
  老用户升级后不弹，设置里可以再看一遍。模型、服务和聊天软件也都换成了品牌图标。
- **界面英文版**（已完成）：设置里切换中文 / English，新装的按浏览器的语言自动选。服务端发的报错、卡片、推送和聊天软件里的消息也跟着换；
  英文界面下 Bot 默认用英文回复。应用市场的应用和内置模板都有英文说明，清单里加一段 `en:` 就行。
  中文原文就是翻译的键，改界面文字时在 `en.json` 里补上英文，见 [开发 → 界面文字和翻译](development.md#界面文字和翻译)。

## 还在考虑

- **多个账号**：多个人用同一个服务、共享 Bot、按人分权限。第一阶段把它放在“暂不做”里，有需求再做。和上面的“团队”（一组分工的 Bot）不是一回事。
- **话题自动换**：上下文本来就只带最近 20–39 条消息（Inline & Spill），不会越聊越贵，所以先不做。
- **开放 API**：让脚本和别的程序给 Bot 发消息、派任务、取结果。
- **浏览器插件**：把正在看的网页发给 Bot，或者让 Bot 借用你自己的浏览器。

## 不做

- 绕过验证码或人机校验。遇到这类步骤，Bot 一律请人接手（见 [CONTRIBUTING.md](../CONTRIBUTING.md)）。
