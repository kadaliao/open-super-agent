# 功能一览

简体中文 · [English](features.en.md)

README 里只列了亮点，这里是完整的功能。怎么配置见 [配置](configuration.md)，各部分怎么实现见 [架构](architecture.md)。

## Bot 和对话

- **多个 Bot**：每个 Bot 有名字、头像、人设和自己的对话。回复流式输出，思考过程可以折叠。
  头像可以上传图片，也可以让 AI 按名字和职责生成。
- **讨论串**：针对某条消息回复，在旁边单独聊，主对话不被打断。讨论串里有 Bot 的新回复时，对话底部浮一条提醒，
  点了直接打开；对话顶上的“讨论串”按钮列出这个对话的全部讨论串。没看过的回复刷新、换设备都还在，在一处看过各处一起去掉。
- **群聊**：2–6 个 Bot 一个群。
  - `@` 谁谁回答，`@所有人` 大家都说；不 @ 的消息由协调者接，它会分给合适的 Bot。
  - Bot 之间能交接工作，比如一个查完资料，自动交给另一个写总结。
  - 要你确认的操作只出现在各自的私聊里。
- **Bot 之间私信**：不用拉群，Bot 也能私信另一个 Bot 请它帮忙（“让 postman 看看有没有 Anthropic 的邮件”）。
  对方在自己的私聊里处理，做完结果自动回到原来的对话，再由它告诉你。
- **主 Bot 管理 Bot**：Bot 的增删查改都能在对话里让主 Bot 做。
  - 查：“我有哪些 Bot”“Radar 配了哪些技能和定时任务”，它看了每个 Bot 的完整资料再回答。
  - 建：“建一个专门找资源、存网盘的 Bot”，它写好名字、职责、头像和要带上的技能。
  - 改：“给 Radar 的职责加一条只看 AI”“把 Researcher 改名叫 Deep”，名字、职责、头像、技能都能改；改职责时只动你要改的地方，
    卡片上把删掉的划掉、加上的标绿。别的 Bot 的定时任务主 Bot 直接看、建、改、停、删，不弹卡片。
  - 删：卡片上写着会一起删掉什么（私聊记录、技能、定时任务、它的记忆，会退出哪些群），删了不能恢复。
  - 新建、修改、删除每次都弹卡片，你点了才做；不同意可以附一句意见，它按意见改了重提。
    职责想自己改几句的，在卡片上点“编辑”直接改，按你改的建。
  别的 Bot 也能改它自己；要建、删或改别的 Bot，它会私信主 Bot，同样要你确认。
- **后台任务**：耗时的活交给 Worker 在后台做，你可以接着聊。**Heavy 模式**下几个 Worker 各做一遍，再互审汇总。
- **记忆**：
  - 每个 Bot 记得你的偏好和它做过的事；名字、时区这类关于你的基本事实，所有 Bot 共享。
  - 说“记住……”就行，也能在右栏查看、修改、删除，或者从 ChatGPT 等助手导入。
  - 聊久了点“新话题”，之前的对话不再带进上下文，记忆还在。
  - 记忆和资料库能按意思找：Bot 会自己去查以前记下的事和做过的页面。

## 电脑

- 所有 Bot 共用一台电脑，几个任务可以同时用，每个任务一个浏览器窗口。登录状态和文件共用，不用排队。
- 网页通过 CDP 直接控制：按元素操作、读页面文字，比看截图估坐标更快、更准，也更省 token。
- 你能实时看屏幕，随时接手、交还；遇到验证码、登录这类步骤，Bot 会请你来做。
- 电脑可以是这三种之一，前两种不花钱：
  - 本机：桌面 App 默认用它，不用 Docker。Bot 有自己的浏览器窗口（配置和你日常用的分开），给了权限还能看整个屏幕、用你的鼠标键盘操作别的 App；
    服务放在服务器上时，在 Mac 的桌面 App 里选“本机”，服务器上的 Bot 就用这台 Mac；
  - 本地 Docker 里的 Linux 桌面（Chromium 和终端）；
  - [Instabox](https://instabox.sh) 云电脑。
- 用本机时更谨慎：上传文件、写文件、点“发送 / 发布 / 付款”都先问，文件只能放在工作文件夹里，终端默认关；
  每个任务第一次用屏幕先问，你一动鼠标键盘 Bot 就停下。

## 应用、技能、模板

- **应用市场**：侧栏“应用”里挑应用连接，现在收录了 40 个。
  - Notion、flomo、腾讯文档、钉钉、滴答清单、Todoist 等：点一下，用账号登录。
  - Gmail、QQ 邮箱、飞书、企业微信、GitHub：填一个密码、token 或链接。
  - Slack：建一个应用后登录。也能接任意 MCP server。
  - 聊天里用 `@应用名` 指定。每个应用是一份清单文件，[写一份提个 PR](apps.md) 就能上架。
  - 应用自带界面（MCP Apps）的：Bot 用了它，界面就显示在任务结果下面，能直接点；界面里的写操作照样先问你。
- **技能**：输入 `/名字` 调用可复用的做事方法。
  - 可以让 Bot 把刚才的做法存成技能，也能在右栏编辑。
  - **演示一遍**：在电脑上亲手做一次，Bot 把录下的操作整理成技能草稿给你审核。
  - 技能可以导出成文件、生成分享链接，别人粘贴链接就能装；Claude 等用的 `SKILL.md` 也能直接导入。
- **Bot 模板**：新建 Bot 时挑一个现成的（资讯助手、邮件管家、项目观察员、出行助手），技能和定时任务都配好了。
  自己调好的 Bot 也能做成模板分享，[写一个模板](templates.md)提 PR 就能放进内置。

## 资料库、图片和链接

- **资料库**：Bot 做好的报告和网页存成页面，可以置顶、生成分享链接；共用电脑里的文件可以浏览、上传、下载。
- **每个 Bot 的资料库**：右栏“资料库”按时间列出这个 Bot 交给你的所有东西（页面、发过的文件、画的图、回复里的链接），能按类筛选、搜索，点开就是原件，任务做的能跳到那次任务的过程。
- **小应用**：要一个能操作的界面（报名表、看板、计算器、按一下就去查的面板、每天更新的仪表盘），Bot 做出来直接显示在对话里。
  界面里能调 Bot 的工具（要确认的照样弹卡片）、存自己的数据（Bot 也能读写，所以能“每天 9 点更新看板”）、替你给 Bot 发消息。
  页面在沙箱里跑，碰不到站点的数据，只能做清单里允许的事。
- **图片和文件**：
  - 聊天时直接发附件：图片显示成缩略图，其他文件显示成卡片。
  - 对话模型能看图时，Bot 直接看你发的图，不用派任务。
  - Bot 也能把电脑里的截图、表格、文档发进对话。
- **画图**：说“画一张……”，Bot 先弹卡片问你（写着描述、模型和价格），允许后几秒出图；画好的图能下载、设为头像。
- **链接卡片**：对话里的链接自动展开。YouTube、B 站点了就在对话里播放，X 的推文直接显示，其他网页显示标题、摘要和配图。

## 定时任务

- 每个 Bot 有自己的定时任务：每天 / 每周几定时、每隔一段时间、webhook。
- 可以暂停、恢复、测试，保留最近 20 次运行记录。设置里的“定时任务”列出所有 Bot 的，每个都能直接开关。
- 在对话里说“每天 9 点帮我……”就能建；“我有哪些定时任务”“早报改成工作日 8 点半”“github 那个先停掉”“把它删了”也都能直接说，在聊天软件里也一样。主 Bot 能管所有 Bot 的（比如“所有定时任务全部停掉”），别的 Bot 只管自己的。
- webhook 事件先过关键词过滤，再交给便宜的模型判断要不要处理。

## 安全和费用

- **先问再做**：写操作先弹卡片问你（允许一次 / 拒绝 / 总是允许），规则在设置里管。
- **保险库**：密钥加密保存，不进聊天记录。
- **费用看得见**：按角色、任务和天统计 token 和金额，有每日预算。
- **观测**：侧栏“观测”页看今天、7 天、30 天或全部的情况，能只看一个 Bot：
  - 花了多少（和上一段比）、token 和缓存命中、做了几个任务、成功多少、平均多久、定时任务跑了几次、多久开始回复、出了几次错
  - 每天（今天按小时）的费用、token、任务、模型调用，按 Bot 叠起来看
  - 需要留意：失败和中断的任务、模型和工具出的错，一样的合成一条，点一下看那次任务的过程
  - 各个 Bot、各个模型（调用、出错、费用、缓存命中、多久出第一个字、每秒多少 token）、各个工具（次数、出错、被拒绝、用时）、定时任务（跑了几次、结果、费用，能直接开关）、按星期和钟点的忙闲、最近的任务
  - 一次次模型调用的明细，能导出 CSV
- **Watchdog**：自动取消卡住、死循环或超预算的任务。
- **登录**：设了 `OSA_PASSWORD` 就要先登录；不管开没开登录，别的网站都没法借你的浏览器连上来。见 [SECURITY.md](../SECURITY.md)。

## 在哪用

- **网页**：电脑和手机的浏览器都行。手机上也能看屏幕、接手电脑打字、处理确认，有语音输入。
- **macOS 桌面 App**：
  - 安装包约 45 MB，自带运行环境，不用装 Docker 和 Python；Bot 直接用这台电脑（浏览器，给了权限还有屏幕和鼠标键盘）。
  - 关掉窗口后在菜单栏接着跑；要你确认的操作、做完的任务发系统通知。
  - 也能当客户端连到你的服务器。见 [桌面 App](desktop.md)。
- **iPhone App**（TestFlight 内测）：用相机扫电脑上的二维码连接；推送经过加密中转，App 关着也能收到，锁屏上显示内容，点一下打开对应的对话。见 [iPhone App](mobile.md)。
- **聊天软件**：在 Telegram、飞书、钉钉、企业微信、Discord 里直接和 Bot 说话，和网页上是同一个对话。
  - 要你确认的操作变成消息里的按钮；发文件、发语音（钉钉、企业微信）也行。
  - 服务器不需要公网地址，[几步就能连上](channels.md)。
- **推送**：没开着页面时，需要你确认的事、做完的任务推送到手机或电脑。

## 模型、语言和数据

- **模型自选**：在设置里添加模型服务（DeepSeek、OpenAI、OpenRouter、硅基流动、阿里云百炼、智谱、Kimi、Ollama，
  或任何兼容 OpenAI 的接口），填 API Key、点一下测试就能用。对话、后台任务等各自选模型，单价自动获取。
- **中文 / English**：界面、通知和聊天软件里的消息都有中英文两种，设置里一键切换；英文界面下 Bot 默认用英文回复。
- **备份与迁移**：全部数据（连同密钥）导出成一个加密文件，换机器、从本机搬到服务器时上传就能接着用；
  服务器上也能用命令行定时备份。
