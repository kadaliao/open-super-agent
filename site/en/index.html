An AI teammate with its own computer

open-super-agent is a self-hosted, always-on AI teammate. It browses, fills in forms and downloads files on its computer while you watch the screen live, and hands over to you for captchas and logins. Open source, an alternative to Grok Bot. Bring your own model and pay per token.

A look around

The screenshots use demo data: an indie developer launching “Tidal Notes 2.0”. The user’s messages were written in advance; the Bots’ replies, the tasks and everything on the pages were produced by a real model. The UI is shown in Chinese; it also comes in English.

What it does

Each Bot has its own persona, memory and conversation, and its own computer. You ask, it works, and you can see every step.

  • Chats and delegates

    Long jobs run as background tasks while you keep chatting. Add a word halfway through, get asked when it's unsure, reply to a finished task to keep it going; it carries on after a restart. Put several Bots in a group, and one hands its research to another to write up.

  • Everything you asked for, in one place

    Each request is a card on the Requests board, in To do, In progress, Needs you or Done, grouped into numbered projects. Memory tidies itself up every night, and you can undo it.

  • A computer you can watch

    Bots browse, fill in forms and download files while you watch live, each task in its own browser window. The computer can also be your Mac: with permission, Bots use apps like WeChat and Finder, and stop as soon as you move the mouse.

  • Finds what's new

    Web search and page reading use free services by default, with no API key to fill in. You can switch to DeepSeek, Tavily and others; when a paid one is in use, the settings say whose account pays. Bots can also search posts on X, Reddit and Xiaohongshu with like and comment counts.

  • Connects to your apps

    40 apps in the market, including Notion, Gmail, GitHub, Feishu, DingTalk and Tencent Docs. Any MCP server works too.

  • Writes documents with you

    Edit documents directly, select a passage and @ a Bot, and it makes the change and replies in the comments. Share a link and anyone can read it without logging in.

  • Asks first, any model

    Sending mail, submitting forms and similar actions show a card first, and secrets are encrypted in a vault. DeepSeek, Kimi, Zhipu, OpenAI, Ollama on your machine, or any OpenAI-compatible endpoint, with the cost on the Insights page.

  • Show it once, run it on time

    Do a task once and it becomes a skill. Say “every day at 9, …” for a routine, or “tell me when this page changes” for an event.

  • Your data stays yours

    It runs on your own machine. All data, secrets included, exports as one encrypted file you can carry to another machine.

Where you use it

The same Bots, always on in one place, reachable from wherever you are.

  • macOS app

    Download the dmg and open it: about 40 MB, no Docker or Python. It keeps running in the menu bar after you close the window.

    Desktop app docs

  • Server

    One docker compose up on a VPS or a machine at home. Connect from a browser, the app, your phone or a chat app.

    Docker docs

  • iPhone appTestFlight

    Scan a QR code on your computer to connect. Approvals and finished tasks are pushed to your phone, encrypted.

    iPhone app docs

  • Chat apps

    Talk to your Bots from Telegram, Feishu/Lark, DingTalk, WeCom or Discord, with approvals as message buttons.

Get started

The first time you open it, a short guide walks you through adding a model provider, meeting your Bot and connecting an app. Models run at the provider, so no GPU is needed.

On a Mac

macOS 12 or later, Apple silicon or Intel, 8 GB of RAM or more.

  1. Download the dmg for your chip from the releases page, or use Homebrew: 
    brew install --cask kadaliao/tap/open-super-agent
  2. Open the app and choose “Run on this computer”.

On a server

You only need Docker. With a cloud computer, 1 core and 1 GB is enough; with the local Docker computer, 4 cores and 8 GB is recommended.

  1. Clone and start it: 
    git clone https://github.com/kadaliao/open-super-agent.git
cd open-super-agent
cp .env.example .env  # optionally add DEEPSEEK_API_KEY
docker compose up -d  # first build takes 5–10 min
  2. Open http://127.0.0.1:8765. For automatic HTTPS and backups, see the deployment docs (Chinese).

Turn on login before going public. Login is off by default, so run it on localhost or a private network such as Tailscale. For the public internet, set OSA_PASSWORD and serve it over HTTPS. See SECURITY.md.
