会聊天，会派活，还有一台自己的电脑

open-super-agent 是可以自己部署的常驻 AI 队友。它在电脑上查资料、填表、下载文件，你能实时看屏幕，遇到验证码和登录随时接手。开源，可替代 Grok Bot；模型自选，按 token 计费。

它能做什么

每个 Bot 有自己的人设、记忆和对话，也有自己的电脑。你说一句，它去做，做的每一步都看得到。

  • 会聊天，也会派活

    耗时的活交给后台任务，你接着聊。做到一半能补一句，拿不准时它停下来问你，做完回一句就接着做，服务重启了也接着做。几个 Bot 能拉群，一个查完资料，自动交给另一个写总结。

  • 交代过的事一眼看到

    每件事一张卡，在“需求”看板上按待办、进行中、等你处理、已完成排好，卡片归到项目下、带编号。记忆每天夜里自己整理，过期的不再读，不满意能撤销。

  • 一台能看、能接手的电脑

    Bot 在电脑上查资料、填表、下载文件，你实时看屏幕，几个任务各开一个浏览器窗口。电脑也可以就是你的 Mac：给了权限，它能操作微信、访达这些 App，你一动鼠标它就停下。

  • 查得到最新的

    搜网页、读网页默认走免费的服务，不用填 API Key；想换 DeepSeek、Tavily 这些也行，用到收费的会写明钱从哪扣。还能搜 X、Reddit、小红书上的帖子，带点赞和评论数。

  • 连上你在用的应用

    应用市场收录了 40 个，Notion、Gmail、GitHub、飞书、钉钉、腾讯文档……也能接任意 MCP。

  • 和 Bot 一起写文档

    文档你直接编辑，选中一段、@ 某个 Bot，它就来改、在评论里回你。生成一个链接，别人不用登录就能看。

  • 先问再做，模型随便换

    发邮件、提交表单这类操作先弹卡片问你，密钥加密存在保险库里。DeepSeek、Kimi、智谱、OpenAI、本机的 Ollama，任何兼容 OpenAI 的接口都行，花了多少在观测页里看。

  • 教一遍就会，到点就做

    演示一遍就成了技能。说“每天 9 点帮我……”就建好定时任务，说“这个网页有变化就告诉我”就建好事件。

  • 在国内好用，数据在你手里

    飞书、钉钉、企业微信里直接说话；默认不需要国外的付费服务。跑在你自己的机器上，全部数据能导出成一个加密文件。

开始用

第一次打开会有引导：接上一个模型服务、认识你的 Bot（或从模板装一个）、连一个常用应用。模型跑在模型服务那边，不需要显卡。

在 Mac 上

macOS 12 以上，Apple 芯片或 Intel，8 GB 内存起。

  1. 到发布页下载对应芯片的 dmg，或者用 Homebrew： 
    brew install --cask kadaliao/tap/open-super-agent
  2. 打开 App，选“在这台电脑上运行”。

在服务器上

只需要装 Docker。用云电脑时 1 核 1 GB 就够，用本地 Docker 电脑建议 4 核 8 GB。

  1. 拉代码，起服务： 
    git clone https://github.com/kadaliao/open-super-agent.git
cd open-super-agent
cp .env.example .env  # 可以先填 DEEPSEEK_API_KEY
docker compose up -d  # 第一次构建 5–10 分钟
  2. 打开 http://127.0.0.1:8765。自动 HTTPS、国内镜像源、备份见部署说明。

放到公网前先开登录。默认不用登录，只适合本机或内网（例如 Tailscale）。部署到公网，先设置 OSA_PASSWORD，再用 HTTPS 访问，见 安全说明。
